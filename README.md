# Section Analysis Tool

A Fusion 360-style section analysis tool for Blender 4.2+.

## Features

- **Cross-section visualization**: Create section cuts through mesh objects
- **Multiple axes**: Cut along X, Y, or Z axes
- **Distance control**: Position the cut at any distance from origin
- **Rotation support**: Rotate cutting plane around the selected axis
- **Wireframe display**: Toggle wireframe visualization of cutting plane
- **Clear functionality**: Remove all section analysis elements

## Installation

1. Download this package as a ZIP file
2. In Blender, go to Edit > Preferences > Add-ons
3. Click "Install..." and select the ZIP file
4. Enable the add-on

## Usage

1. Select mesh objects you want to analyze
2. Open the Section Analysis panel in the 3D View Sidebar (N-key)
3. Configure cut parameters:
   - Choose axis (X, Y, Z)
   - Set distance from origin
   - Adjust rotation angle
   - Toggle wireframe display
4. Click "Apply Section Analysis"
5. Use "Clear Section Analysis" to remove all sectioning

## Requirements

- Blender 4.2 or higher
- Python 3.11+
